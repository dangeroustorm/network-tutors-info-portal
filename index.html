Router Connection Guide

Follow these 4 simple steps to set up your router in Wohnanlage Chiemgauer Str.

Connect Cable to Blue WAN Port

Plug the network cable coming from your room's wall socket directly into the BLUE WAN Port on the back of your TP-Link router.

Important Rule: Never plug the wall cable into an orange LAN port. Plugging into LAN creates network loops that automatically disable internet access for your floor.
Click any port on the router diagram to inspect its function.
Router Rear Panel Overview

Open Router Admin Dashboard

Connect your laptop or smartphone to the router via Wi-Fi or LAN cable. Open your web browser and enter the default management IP address.

Router Address
http://192.168.0.1
Alternative: tplinkwifi.net
Default Login
Username: admin | Password: admin
You will be asked to set a new password on first login.

Select WAN Connection Type: Dynamic IP (DHCP)

Inside the TP-Link Quick Setup menu, select Dynamic IP as your connection mode. The dormitory network automatically assigns your router an IP address.

Quick Setup Summary:
  • Click Quick Setup in the left navigation menu.
  • Choose Wireless Router mode.
  • WAN Connection Type: Select Dynamic IP (Do NOT choose PPPoE or Static IP).
  • MAC Clone: Keep Do NOT clone MAC address.

Set Wi-Fi Name & Password

Set a clear wireless network name (SSID) like Dorm718_RoomXXX and protect it with a strong password.

Wi-Fi Password Generator
Recommended Settings
• Wireless Security: WPA2-PSK (AES)
• Mode: 802.11b/g/n mixed
• Channel: Auto

Network Security Rules

Please adhere to university network regulations to ensure stable service and legal compliance.

Essential Network Rules

Unified guidelines for Wohnanlage Chiemgauer Str. residents

No Rogue DHCP Servers: Always connect the wall cable exclusively to the blue WAN port. Connecting to LAN disrupts floor connectivity.
No Copyright Infringement (BitTorrent / P2P): Peer-to-peer file sharing of copyrighted media is strictly monitored in Germany. Infringements lead to heavy legal fines (Abmahnung).
Router Password Security: Change your router admin login from 'admin' to prevent unauthorized changes by neighboring devices.
Personal Residential Use Only: Bandwidth is for academic research and residential internet use. Commercial hosting or reselling connectivity is forbidden.
